# 祀·协议主题设计

日期：2026-11-10
状态：用户已选择并确认方向

## 变体卡

- 变体：祀·协议（黄色 / 纸白灰绿 / 标准切角 / 淡龙纹与工程斜线 / 标准密度 / 短机械感动效）。
- 主视觉：原创几何“祀”标识、原创抽象龙纹、DeepSeek Harness 自身会话内容；不使用预览图中的角色立绘或任何游戏官方素材。
- 页面类型：新会话页为展示页，对话、设置与插件管理为阅读页；不改变现有功能与信息架构。

## 参考图提取

用户提供的两张预览图包含：纸白灰绿、括号大标题、黄色任务标记、左侧当前导航、细线分区、斜线工程纹、宽幅角色视觉。实现保留这些结构与配色特征，不复制其中的人物、龙、Q 版角色或其他第三方图像。

## 实现范围

1. 更新浅色与深色 Theme 令牌为纸白灰绿体系，保留 `#FFFA00` 单一强调色。
2. 新会话 `conversation.hero.brand.mark` 注册原创“祀”标识与抽象龙纹；装饰不拦截输入，并在窄屏隐藏大幅背景。
3. `conversation.composer.dock` 增加简洁的 `[ 祀 ] / SI` 主题标记，使用 slot 已有空间，不固定遮挡聊天。
4. 页顶三色条改为灰绿 / 黄 / 浅灰绿。
5. 一级标题使用括号结构，二级标题保留 `//`；标签与数字使用 Saira 宽体和等宽数字。
6. 当前导航使用黄色填充与字重，发送按钮使用黄底墨字；按钮切角不压文字。
7. 更新插件图标、双语元数据、README、NOTICE 和版本号。
8. 保留键盘焦点、减少动效、浅色/深色切换与插件卸载清理。

## 原创视觉

- 标识：括号中的“祀”字与几何龙角、折线、黄色小方块，使用系统黑体与原创矢量路径。
- 龙纹：由开放折线、切面与留白构成的抽象轮廓，不临摹参考图的角色或龙。
- 资源：组件内联 SVG 与 CSS，无运行时图片请求；图标为独立原创 SVG。

## 验证

- 先让新增验收在旧实现上失败，再实现到通过。
- JavaScript 语法、Theme 令牌、两个新增 slot、原创 SVG、资源内嵌、无外部 URL、无预览图哈希。
- 重新安装并检查 `conversation.hero.brand.mark`、`conversation.composer.dock` 与 `shell.overlay`。
- 如果更新需要重启，按 Plugin Manager 的 `nextStep` 交付，不声称即时视觉生效。
- 浏览器视觉验证不可用时明确报告，不以安装状态替代截图验收。

## 本地立绘补充（2.1.0–2.1.1）

用户随后明确提供一张祀立绘并要求作为主背景。`feat/si-local-illustration` 分支将 `assets/si-background.jpg` 内嵌到新会话背景，使用全幅 cover 布局。原有小标识保留，大抽象龙纹不再作为新会话主视觉。

2.1.0 曾在立绘上叠加纸色渐变，导致深浅主题的左侧内容都被覆盖层压暗。2.1.1 删除覆盖层，改为仅对立绘本身应用左侧透明渐隐，避免遮挡应用内容，并加入防止纸色渐变回归的静态测试。
